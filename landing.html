Local LLM inference on your GPU and CPU. Python that runs in the page. Tools, files, memory — all in a single tab. The cloud is optional.

01  ·  Runs where you are

Models run on your silicon, not in someone's datacenter.

sandpie ships a hand-written WebGPU inference engine — WGSL kernels tuned for integrated GPUs — and a threaded WASM CPU engine that beats native llama.cpp on the same machine. Ternary, int4, int8: whatever your hardware can carry.

No install. No driver hunt. No API key for the local path. Open a tab, pick a model, and the weights stream once into your browser's storage. From then on it works on a plane.

02  ·  An agent with hands

Chat is table stakes. sandpie executes.

A full Python runtime lives inside the page — numpy, pandas, matplotlib — with its own persistent filesystem. The agent writes code, runs it, reads the result, and iterates. It searches the web, reads pages, renders documents.

Small local models are kept honest with grammar-constrained decoding: tool calls are valid by construction, character by character. Skills, memory and scheduled loops turn a chat window into a workspace.

03  ·  What's in the box

Everything, in one tab.

/01

Local inference

Custom WebGPU + threaded WASM engines. Dense, MoE and ternary models — Qwen3, LFM2, Bonsai, Gemma — at speeds that match or beat native runtimes on the same hardware.

/02

Python in the page

A real scientific Python stack via Pyodide, with a persistent private filesystem. The agent computes instead of guessing.

/03

Cloud when you want it

Bring your own API keys for frontier models. Keys live in localStorage, requests go straight from your browser to the provider. There is no sandpie server reading your traffic.

/04

Files & documents

Drop in PDFs, Office files, images. Word and Excel render faithfully in-app through a WASM LibreOffice engine. Conversations, skills and artifacts sync to your own Dropbox — optionally.

/05

Voice

Live on-device speech-to-text with Whisper. Your microphone audio is transcribed locally, like everything else.

/06

Open & hackable

One HTML shell plus small modules. View-source is the architecture diagram.
